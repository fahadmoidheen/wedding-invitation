# Ultra-Premium Cinematic 3D Kerala Wedding Invitation

A fully responsive, luxury digital wedding invitation built with modern web technologies. This project blends traditional Kerala wedding aesthetics with cinematic storytelling, immersive 3D interactions, and premium UI design.

## Features

- **Cinematic Loader**: Animated Kerala lamp lighting and elegant progress reveal.
- **3D Envelope Intro**: Custom Framer Motion envelope opening animation.
- **Parallax Hero**: Immersive scroll effects with beautiful typography.
- **Love Story Timeline**: Animated, glassmorphism vertical timeline.
- **Dynamic Configuration**: All content (names, dates, colors, venues) is driven by `src/config/data.json` for easy customization.
- **Responsive Architecture**: Perfectly scaled for mobile, tablet, and desktop devices.
- **Ambient Audio**: Integrated background music with toggle controls.

## Tech Stack

- **Framework**: Next.js (App Router) & React 19
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion & GSAP
- **3D Effects**: React Three Fiber / Three.js
- **Scrolling**: Lenis (Smooth Scroll)
- **Language**: TypeScript

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
